# Privacy Policy

**Website Code Extractor** · Last updated: September 26, 2026

## What the extension handles

The extension does nothing until you click **Extract & Download**. When you do, it reads the page in your active tab: its URL and its HTML. It then downloads the stylesheets, scripts and images that page links to, directly from the servers that host them, and packs everything into a ZIP file. The page's domain name is used as the ZIP's file name.

## What happens to that data

- Everything is processed locally in your browser.
- Nothing is sent to the developer or to any third party. The extension has no server of its own.
- Nothing is stored by the extension. The only thing kept is the ZIP file you choose to save.
- There are no accounts, analytics, ads or tracking.

## Google Fonts

The extension's popup loads the Raleway font from Google Fonts. When you open the popup, your browser requests the font from Google's servers, which receive your IP address as with any web request. See [Google's Privacy Policy](https://policies.google.com/privacy).

## Permissions

- **activeTab** and **scripting**: read the HTML of the page you're on, only after you click Extract & Download.
- **Access to all websites**: download the page's stylesheets, scripts and images, which are often hosted on other domains such as CDNs.
- **downloads**: save the ZIP to the folder you pick.

## Limited Use

The extension's use of the data it handles complies with the [Chrome Web Store User Data Policy](https://developer.chrome.com/docs/webstore/program-policies/user-data-faq), including the Limited Use requirements. Data is used only to create the ZIP file you asked for. It is never sold, transferred or used for any other purpose.
